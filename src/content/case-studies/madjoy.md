## Project Overview

**Madjoy** is a digital platform where users can purchase a wide range of **gift cards and gift vouchers** while earning cashback on every eligible purchase. The platform required a modern, secure, and scalable build that could handle shopping flows, payments, user accounts, and admin operations seamlessly.

Dotix designed and developed a complete **multi-functional e-gift card store** for Madjoy—built for speed, trust, and smooth user experience.

---

## What We Created

Dotix delivered a full-scale digital store experience tailored for e-commerce reliability. The website includes a wide catalog of e-gift cards, a clean browsing experience, and smooth purchase flows. Users can log in, manage their profile, add items to cart, checkout securely, and track the delivery of their purchased gift cards.

A secure **payment gateway integration** ensures frictionless transactions, while the built-in **delivery tracking system** updates users about the status of their digital purchases.

We added a dedicated **contact form** for user support, keeping communication simple and accessible.

On the backend, Dotix developed a complete **admin panel** that enables Madjoy’s team to manage gift card inventory, track orders, view analytics, process user queries, and oversee platform performance.

---

## Tech Stack Used (And Why)

### Next.js, Tailwind CSS (Storefront)

Madjoy’s customer-facing store was built using **Next.js** for its performance, routing capabilities, and SEO advantages. Combined with **Tailwind CSS**, the platform delivers a clean UI, fast loading, and consistent design across all pages.

### Node.js, Express.js, MySQL (Backend & Database)

The backend was built with **Node.js** and **Express.js** to create scalable and secure APIs. **MySQL** was used as the primary database to handle structured data such as transactions, orders, user accounts, and gift card listings.

This combination ensures stability, data integrity, and fast communication between the frontend and backend.

## Impact & Results

With a modern interface and smooth checkout flow, users now browse, buy, and track gift cards effortlessly.

An efficient admin panel and simplified operations, Madjoy can now scale its catalog, run promotions, and handle growing traffic with confidence.

Dotix built a robust, scalable, and user-friendly digital store that empowers Madjoy to deliver secure and seamless gift card purchasing experiences. From frontend design to backend engineering, the platform is optimized for performance, growth, and long-term reliability.
