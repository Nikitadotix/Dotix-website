## Project Overview

Founders, designers, agencies, and product teams all run into the same wall: turning an app idea into something real on the App Store and Google Play usually means hiring an Android developer and an iOS developer before you've validated anything. Most "no-code" tools don't solve this — they wrap a web page in a native shell and call it an app.

We built **duddy.io** to close that gap: an **AI-enabled, no-code app builder** where you design a screen, describe what you want, or wire the logic yourself — and get back a real Android, iOS, and web build.

---

## The Services Behind duddy.io

duddy.io isn't a single app — it's a set of services working together:

- **Builder** - where all the app designing, screen logic, and project building happens
- **Dashboard** - for managing projects across a team
- **Backend** - the infrastructure that powers builds, storage, and project data
- **Website** - the public-facing duddy.io site
- **Payments & Subscription Management Dashboard** - handles billing and plan management
- **Authentication Service** - sign-in and account management across the platform
- **Documentation** - guides and references at docs.duddy.io
- **Affiliate Dashboard** - for partners promoting duddy.io

## Three Things duddy.io Actually Does

**AI Agent** — Describe a screen in a sentence and duddy.io's AI lays it out, pulls components from your theme, and wires the logic needed to make it work — including the parts you didn't think to mention.

**Build & Export, Native** — One project compiles into a real Android **.apk**/**.aab**, an iOS **.ipa**, and a web **PWA** — not a website wrapped in a shell. Native source export (Java for Android, Swift for iOS) is on the roadmap.

**Drag & Drop Design and Logic** — A visual canvas for placing components by hand, paired with logic blocks for events, conditions, API calls, and storage that only snap together when they belong together — no scripting required.

Everything else in the builder — templates, Figma import, live collaboration, and more — is best explored directly on [duddy.io](https://duddy.io).

---

## Technology Stack & Strategic Choices

**Frontend**: **Next.js** and **React** power the builder interface and the marketing site, giving us fast page loads and a component-based architecture that scales as we add more of the canvas, logic-block, and dashboard surfaces.

**AI Layer**: An integrated AI model drives screen generation — turning a plain-language description into a laid-out screen matched to the project's own theme, with logic blocks already wired in.

**Backend Integrations**: Projects connect directly to **Firebase** for authentication, database, and storage, so builders get a working backend without writing any glue code themselves.

**Build System**: A dedicated compile pipeline turns one project into platform-specific artifacts — Android, iOS, and web — letting someone go from a blank canvas to an installable build without ever touching Android Studio or Xcode.

## Conclusion

duddy.io exists because building a real mobile app shouldn't require assembling a team before you've proven the idea. An AI agent, a true drag-and-drop canvas, and visual logic blocks all point at the same compile pipeline — so describing, dragging, and wiring are just three ways to edit the same project, and what comes out the other end is an actual Android and iOS build.
